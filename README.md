# Sentiment-Analysis-on-IMDB-Move-Reviews
Sentiment Analysis on IMDB Movie Reviews

Sentiment Analysis done on IMDB movie reviews in order to answer questions such as 	What aspects matter to viewers per movie genre, what’s the relationship between budget and revenue, and what are some trends in movie genres and 	Does review sentiment reflect and predict how audiences and critics actually felt about a movie, and does it relate to real-world outcomes like budget or box office success?

The conclusion was that : how positively a movie is reviewed shows no
meaningful relationship with how much it cost or
earned​

​

Sentiment did correlate strongly with user rating, so the
model captures real audience feeling, just not box office
outcomes​
